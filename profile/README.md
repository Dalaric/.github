**house-style-check**

A copy checker with no dependencies. Standard library Python, nothing to
install, runs over a folder of Markdown, HTML, JSON or text and fails a build
on the writing habits you've decided you don't want.

I've run one learning platform since 2000. It's changed hosting more than once
without incident and has never needed rewriting to survive a move. That's most
of what's worth knowing about how I work.
